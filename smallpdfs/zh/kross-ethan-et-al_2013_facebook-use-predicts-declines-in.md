摘要 每天有超过5亿人使用 Facebook。然而，Facebook 的使用是否会随着时间影响主观幸福感尚不清楚。我们使用经验采样方法解决了这一问题，这是测量实时行为和心理体验最可靠的方法。我们在两周内每天给参与者发送五次短信，以研究 Facebook 的使用如何影响主观幸福感的两个组成部分：人们的即时感受以及对生活的满意度。我们的研究结果表明，Facebook 的使用会随着时间推移导致这两个变量的负向变化。在某一时间点使用 Facebook 越多，下一次收到我们短信时的感受就越差；在两周内使用 Facebook 越多，生活满意度水平随时间下降得越多。与他人的“直接”互动并不预测这些负面结果。这些结果也不受用户 Facebook 网络规模、感知支持度、使用 Facebook 的动机、性别、孤独感、自尊或抑郁的调节。从表面上看，Facebook 为满足基本的人类社交需求提供了宝贵的资源。然而，这些发现表明，Facebook 可能削弱而不是提升幸福感。 引用：Kross E, Verduyn P, Demiralp E, Park J, Lee DS 等. 引言 在线社交网络正在快速改变人类互动的方式。全球有超过十亿人属于Facebook，这是世界上最大的在线社交网络，其中超过一半的人每天登录[1]。然而，到目前为止，没有研究考察过与Facebook互动如何随时间影响主观幸福感。事实上，最近一篇文章审查了2005年1月至2012年1月期间关于Facebook的所有同行评审出版物和会议论文（共412篇），却没有发现任何一项研究探讨使用这项技术如何随时间影响主观幸福感（文本S1）[2]。主观幸福感是行为科学中研究最广泛的变量之一。虽然自身具有重要意义，但它也预测了一系列显著的益处，包括健康改善和寿命延长[3–5]。鉴于Facebook使用的频率，识别与这项技术互动如何影响主观幸福感是一个基础研究挑战，同时具有重要的实际意义。这个问题尤其棘手，因为先前的研究提供了关于Facebook使用应如何影响主观幸福感的不同线索。一些横断面研究显示，在线社交网络使用（尤其是Facebook）与幸福感之间存在正相关[6]，而其他研究显示相反的结果[7,8]。还有研究表明，Facebook使用与幸福感之间的关系可能更为复杂，并可能受到多个因素的影响，包括Facebook好友数量、对在线社交网络的支持感知等。

### 使用 Facebook 预示幸福感下降

随着时间推移，主观幸福感的变化尚不清楚。我们通过对体验采样数据进行滞后分析来解决这个问题，这种方法使我们能够利用参与者自然发生的行为和心理状态的相对时间顺序，推断其可能的因果顺序[17,18]。这些分析表明，使用 Facebook 会预测主观幸福感两个组成部分的下降：人们的即时感受以及对生活的满意度。关键是，我们没有发现支持两种合理替代解释的证据。首先，与他人的“直接”互动并未预测幸福感下降。实际上，直接的社交网络互动会随着时间让人们感觉更好。这表明，Facebook 的使用可能构成了一种独特的社交网络互动形式，会预测幸福感的降低。其次，多种类型的证据显示，不存在因人们在情绪低落时更可能使用 Facebook 而导致幸福感下降的情况——既没有情绪也没有焦虑预测 Facebook 的使用，并且即使在控制孤独感（孤独感确实预测了 Facebook 使用量增加并降低了情感幸福感）后，Facebook 使用仍继续预测幸福感显著下降。参与任何孤独活动是否也会类似地预测幸福感下降？我们怀疑不会，因为人们常常从某些孤独活动中获得乐趣（例如，运动、阅读）。支持这一观点的是，一些近期研究表明，人们对社会孤立的感知（即他们感到孤独的程度——本研究中评估的一个变量，对我们的结果没有影响）比客观社会孤立更能决定幸福感[25]。一个相关问题是，参与任何互联网活动（例如，电子邮件、网页浏览）是否也会预测幸福感下降。这里的先前研究同样表明，它不会。
许多研究表明，是否与互联网互动会预测幸福感的变化取决于你如何使用它（即你访问哪些网站）以及你与谁互动 [26]。

这些结果的另一种替代解释是，人们在情绪不好时使用 Facebook（即在感到无聊、孤独、担忧或其他困扰的时候），而情绪不好导致幸福感下降，而不是 Facebook 使用本身导致的。我们之前报告的分析部分解决了这个问题，证明情绪不能预测 Facebook 使用随时间的变化，并且在控制情绪的情况下，Facebook 使用仍然显著预测随着时间的生活满意度下降。然而，由于参与者每次我们通过短信联系他们时，也会评估他们感到的孤独和担忧程度，我们能够进一步检验这一假设。我们首先考察了担忧或孤独是否预测 Facebook 使用随时间的变化（即 T1 担忧 [或 T1 孤独] 预测 T1–2 Facebook 使用，同时控制 T0–1 Facebook 使用）。担忧未能预测 Facebook 使用的变化，B = .04, x2 = 2.37, p = .12，但孤独可以，B = .07, x2 = 8.54, p < .01。某一时间点感觉越孤独的人，随着时间他们使用 Facebook 越多。鉴于这一显著关系，我们接下来考察了在控制孤独后，Facebook 使用与情感和认知幸福感变化之间的关系是否变得不显著——如果 Facebook 使用是孤独的代理变量，这是可以预测的结果。事实并非如此。在每次分析中，当控制孤独时，Facebook 使用仍然预测情感幸福感的下降，B = .08, x2 = 27.87, p < .0001，以及认知幸福感的下降，B = 2.012, b = 2.126, t(72) = 2.34, p = .02。担忧和孤独都未显著与 Facebook 使用交互以预测情感或认知幸福感的变化（p > .44）。调节作用。

### 使用 Facebook 预示幸福感下降

Facebook 使用与幸福感之间的关系从基础科学和实际应用的角度来看都很重要。最后，虽然我们在本研究中使用的分析方法对于推断自然发生变量之间关联的可能因果顺序是有用的，但仍需要在日常生活中操控 Facebook 使用的实验来证实这些发现并建立明确的因果关系。尽管可能难以实施——Facebook 使用的普遍性、其在年轻成年人日常社交互动中的核心地位以及成瘾特性可能使其成为一个难以干预的目标——这样的研究对于扩展这项工作并为未来的干预提供参考非常重要。

### 文本 S3

在得出结论之前，有两个注意事项。首先，尽管我们观察到 Facebook 使用与幸福感之间存在统计学上显著的关联，但这些效应的规模相对“较小”。然而，这并不应削弱它们的实际意义。主观幸福感是一个多因素决定的结果——期望单一因素对其产生强大影响是不现实的。此外，除了本身具有重要性之外，主观幸福感还可以预测一系列心理和身体健康后果。因此，识别任何系统性影响其的因素都是重要的，尤其是当该因素可能在大量人群中随着时间积累时。Facebook 的使用似乎符合这两个标准。其次，一些研究表明，像我们在本研究中所做的那样，要求人们使用单一双极量表来表明他们感觉是好是坏，可能会掩盖关于某一变量是否使人感到不那么积极、更加消极或同时减少积极感和增加消极感的有趣差异。未来的研究应使用两个单极情感问题分别评估积极和消极情感，以解决这一问题。
