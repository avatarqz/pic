我们经常直接在身体中体验情绪。当与心上人在公园散步时，我们轻快地走着，心中充满激动；而在重要的工作面试前，焦虑可能会使我们的肌肉紧绷，手出汗并颤抖。大量研究表明，情绪系统通过调节心血管系统、骨骼肌系统、神经内分泌系统和自主神经系统（ANS）的激活，来准备我们应对环境中的挑战（1）。这种情绪与身体状态的联系也反映在我们谈论情绪的方式中（2）：一位下周要结婚的年轻新娘可能会突然“临阵退缩”，严重失望的恋人可能会“心碎”，而我们最喜欢的歌曲可能会让我们“脊背发凉”。经典（3）以及较新的（4, 5）情绪处理模型都假设，主观情绪感受是由对情绪相关身体状态的感知触发的，这些身体状态反映了骨骼肌系统、神经内分泌系统和自主神经系统的变化（1）。这些自觉的感受帮助个体自愿地微调其行为，以更好地适应环境的挑战（6）。尽管情绪与广泛的生理变化有关（1, 7），但不同情绪相关的身体变化是否足够具体，以作为离散情绪感受（如愤怒、恐惧或快乐）的基础仍存在激烈争论（8, 9），与情绪相关的身体感受的分布地形仍然未知。在此，我们使用一种独特的基于计算机的、地形自我报告方法（emBODY，图1），揭示了与不同情绪相关的身体感受地图。参与者（n = 701）被展示了两个身体轮廓，并配以情绪词语、故事、电影或面部表情，他们被要求在观看每个刺激时，用颜色标记出他们感受到的身体活动增加或减少的区域。

情绪期间身体拓扑独立性。我们提出，有意识感受到的情绪与文化上普遍存在、拓扑上不同的身体感受相关，这可能支持不同情绪的范畴体验。结果 我们进行了五项实验，每项实验的参与者数量为36–302人。在实验1中，参与者报告了与六种“基本”情绪和七种非基本（“复杂”）情绪以及中性状态相关的身体感受，均用相应的情绪词描述。图2显示了与每种情绪相关的身体感觉图。单一剔除法线性判别分析（LDA）将每种基本情绪和中性状态与所有其他情绪进行分类，平均准确率为72%（偶然水平50%），而完全分类（将所有情绪相互区分）平均准确率为38%（偶然水平14%）（图3及表S1）。对于非基本情绪，相应的准确率为72%和36%。在对所有13种情绪及中性情绪状态进行分类时，准确率分别为72%和24%，而偶然水平分别为50%和7%。在聚类分析中（图4，上图），正面情绪（快乐、爱情和自豪）形成一个聚类，而负面情绪分为四个聚类（愤怒与恐惧；焦虑与羞耻；悲伤与抑郁；以及厌恶、轻蔑与嫉妒）。惊讶——既不是负面情绪，也不是正面情绪——属于最后一个聚类，而中性情绪状态则与所有其他类别保持明显区分。我们在一项对照实验中控制了与情绪相关的比喻语言的语言混淆（例如，“心痛”），该实验对象为瑞典母语者，其作为日耳曼语言，与乌拉尔语系的芬兰语属于不同的语言家族。每个基本情绪词相关的身体感觉图在瑞典语和芬兰语样本间相似（平均相关系数r = 0.75），且两次实验间不匹配情绪的相关性（例如愤怒-芬兰语）也存在。意义 情绪在生存关键事件及愉快互动期间协调我们的行为和生理状态。
尽管我们经常能够有意识地意识到自己当前的情绪状态，如愤怒或快乐，但引起这些主观感受的机制仍未得到解决。在此，我们使用了一种地形自我报告工具，发现不同的情绪状态与地形上不同且具有文化普遍性的身体感觉相关；这些感觉可能构成我们有意识情绪体验的基础。监测由情绪触发的身体感觉的地形，为情绪研究提供了一种独特工具，甚至可能为情绪障碍提供生物标志物。作者贡献：L.N.、E.G.、R.H. 和 J.K.H. 设计了研究；L.N. 和 E.G. 执行了研究；L.N. 和 E.G. 提供了新的试剂/分析工具；L.N. 和 E.G. 分析了数据；L.N.、E.G.、R.H. 和 J.K.H. 撰写了论文。作者声明无利益冲突。通过PNAS开放获取选项可在网上自由获得。

属于远离芬兰语的语言家族的一种语言（台湾闽南语：中文）。支持文化普遍性假说，每种基本情绪相关的身体地图在西欧和东亚样本中相似（平均相关系数 rs = 0.70），而两个实验中不匹配情绪之间的相关性（例如，愤怒-芬兰语 vs 快乐-台湾话）明显较低（平均相关系数 rs = 0.40）相较于匹配情绪。当人们回忆与词汇描述的情绪类别相关的身体感觉时，他们可能只是报告情绪相关的身体反应刻板印象。为控制这种可能性，我们直接通过两种最有效的情绪诱导技术（10, 11）在参与者中诱导情绪——基于阅读短篇故事的引导性心理意象（实验2）和观看电影（实验3）——并要求他们在情绪诱导过程中在线报告身体感觉。我们仔细控制故事或电影中没有直接提及情绪类别或特定身体感觉，并且故事的实际情绪内容（图 S1）由另一组72名受试者评估（电影的相应数据见参考文献12）。身体地图与实验1使用情绪词获得的结果相似（图 S2 和 S3）。线性判别分析（LDA）准确率很高（故事为79%和48%，相比单个分类与完整分类的50%和14%的随机水平；电影为76%和50%，相比50%和20%的随机水平）。身体地图在不同情绪诱导条件之间也高度一致（故事 vs. 电影；平均相关系数 rs = 0.79；见表 S2）。具身情绪模型认为，我们通过在自己身体中模拟他人的情绪来理解他人的情绪（13, 14），这意味着在观察他人表达特定情绪时，我们应能够构建他人躯体内脏状态的身体表征。
我们在实验4中通过向参与者展示六种基本面部表情的图片来测试这一假设，而没有告诉他们这些面孔反映了什么情绪（如果有的话），并要求他们为图片中显示的人上色BSM，而不是为观看这些表情在自己身上引起的感觉上色。同样，情绪的BSM在统计上是可区分的（图S4），分类器的准确率也很高（分别为70%和31%，对应一出一和完全分类方案的随机水平50%和14%；图3和表S1）。关键是，获得的BSM

与由情感词语（平均 rs = 0.82）、故事（平均 rs = 0.71）和电影（平均 rs = 0.78）引起的结果高度一致（表 S2）。如果离散的情绪状态与不同的身体感受模式相关，那么人们也应该能够通过他人的身体情绪图（BSM）识别情绪。在实验5中，我们对87名独立参与者呈现了实验1中每种基本情绪的身体情绪图，采用纸笔强制选择识别测试。参与者的表现与线性判别分析（LDA）相似，平均准确率为46%（对比随机水平的14%）。愤怒（58%）、厌恶（43%）、快乐（22%）、悲伤（38%）、惊讶（54%）和中性状态（99%）的分类准确率较高（χ²检验对比随机水平 P < 0.05），而恐惧的表现未超过随机水平（8%，无显著性）。最后，我们构建了涵盖实验1–4中六种基本情绪及中性情绪状态的身体情绪图相似矩阵（图 S5）。各基本情绪的身体情绪图在各实验中保持一致（平均 rs = 0.83）。尽管不同实验中不同情绪之间存在显著相关（例如实验1的愤怒与实验2的恐惧），但这些相关显著低于匹配情绪之间的相关（平均 rs = 0.52）。相似矩阵的聚类显示出数据的明显层次结构（图4，下部）。悲伤、厌恶、恐惧和中性情绪状态较早地分离成独立簇。文字和面孔实验中的愤怒拓扑聚在一起，而故事实验中的愤怒最初与厌恶结合。两类惊讶情绪图聚在一起，而文字实验数据中得到的图则与厌恶相关。只有快乐在各实验中未形成明显聚类。当将LDA应用于跨实验组合的数据集时，完整分类的平均准确率与单个实验中相似（40% 对比 14% 随机水平）。

结论 我们得出结论，情绪感受与离散但部分重叠的身体感觉图相关，这可能是情绪体验的核心。因此，这些结果支持假设体感（25, 27）和具身性（13, 14）在情绪处理过程中起关键作用的模型。揭示与人类情绪相关的主观身体感觉，可能有助于我们更好地理解诸如抑郁和焦虑等情绪障碍，这些障碍伴随情绪处理的变化（30）、自主神经系统活动（31, 32）以及体感（33）。身体中受情绪触发的感觉在空间分布上的变化，可能提供一种用于情绪障碍的新型生物标记。 材料与方法 参与者 本研究共有773名个体参加（实验1a：n = 302, 平均年龄27岁, 女性261人；实验1b：n = 52, 平均年龄27岁, 女性44人；实验1c：n = 36, 平均年龄27岁, 女性21人；实验2：n = 108, 平均年龄25岁, 女性97人；实验3：n = 94, 平均年龄25岁, 女性80人；实验4：n = 109, 平均年龄28岁, 女性92人；实验5：n = 72, 平均年龄39岁, 女性53人）。所有参与者均以芬兰语为母语，除实验1b的参与者以瑞典语为母语，实验1c的参与者以台湾闽南语为母语。 刺激材料 实验1 a–c：情绪词 参与者评估与六种基本情绪（愤怒、恐惧、厌恶、快乐、悲伤、惊讶）及七种非基本情绪（焦虑、爱、抑郁、轻蔑、骄傲、羞耻、嫉妒）及中性状态相关的身体感觉（BSMs）。每个词以随机顺序呈现一次。参与者的任务是评估在感受每种情绪时，他们通常感觉到身体哪些区域会被激活或抑制，因此任务本身不涉及实际诱导参与者的情绪。实验1a使用芬兰语词汇和讲芬兰语的参与者进行，实验1b使用相应的瑞典语词汇和瑞典语参与者进行，实验1c使用台湾词汇和讲台湾闽南语的参与者进行。
