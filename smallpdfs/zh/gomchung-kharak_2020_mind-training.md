珍贵的宝石和精神朋友，依达姆神灵，以及三宝，我恳求你们，成为我的王冠上的宝石！在成为我的王冠饰物的同时，请关注我无耻的心灵。

(1)

无学之徒向法而行；于无为之思而默想；以善心奉行；于是获益稍多。

对于那些没有法而又心怀卑劣错误意图的假行者，我正在提供作为补救的建议。这将长期帮助你，所以请听好！

（2）

如果我不种地，不砍树，就没有食物可吃。如果不听国王的命令，在臣子的地方，我自己会处于危险之中。

如果我不揭露你的错误，你是不会明白的，笨蛋。如果你不听善意的劝告，你只会变得越来越糟。

(3)

在戒律上我该如何做呢？从苦难中寻找答案。我自己该如何行善？对他人应当多少呢？

你现在的所有痛苦都是因为你过去生中所做的错事。过错在你自己；准备承受苦难。不要自以为道德高尚。

(4)

那么，你好吗？因为我的工作而疲惫吗？没有困扰吗？我应该做什么呢？

现在的所有痛苦和快乐都依赖于过去的业力，所以你没有任何选择——无论发生什么，都把它当作你的朋友。

（5）

这一天的安宁，就现在；如果想要真正的幸福，这一天的心境如何？顺其自然地流淌着。

这生活的快乐是短暂的。如果你想要持久的幸福，你必须心甘情愿地接受生活中所有的小痛苦。

(6)

我想吃饭。 从哪里来的饭？ 很高兴吃饭。 谁喜欢吃饭？

即使是微小的当下痛苦，也能消耗过去行为的苦难，并在未来变为快乐，所以要为苦难培养喜悦。

(7)

这是善良的意志。它不是带有间断的善。它是新的佛法。人们不喜欢它。

逆境是精神上的朋友。障碍激励精神修行。痛苦是恶行的扫帚。不要心烦或把它们看作不幸。

(8)

是源于本质的；是因意志而生的；是因善行而断除的；是多少个？

名声是马拉的诱饵。尊重是束缚的套索。好运是修行的障碍。不要把毒药当作药物。

(9)

如果不被打扰，心中就会安宁；在那些擅长避免干扰的人那里，邪恶将远离。

如果你不切断你投射的观念，无论你做什么，你都永远不会快乐。对于那些看透自己投射的人来说，厄运显得像朋友。

( 10 )

不要依赖自己的心。 不要依赖他人之言。 听从自己心意的教导吧。

如果你不为自己的心灵感到羞愧，别人的指责就是幻觉。不要听从别人的话，而应让自己的心灵成为裁判。

( 11 )

法不是法，是被修改的法。借助于法的因缘所生。不可思议的方法，不可言说。由因缘而现象显现。

不要在此生中自我膨胀，用佛法欺骗自己，行为违背佛法却假装那是佛法。将世俗之事置于脑后。

( 12 )

在这一天，积累功德和利益的两种法；不可争辩地不可避免的事情；坚信的法则之一。

在这两者中，今生的名声与财富，以及帮助来世的法，不要只是随遇而行，或者被任何东西牵着走。一定要修行来世的法。

(13)

坚定的信念不依赖于世俗的循迹。恶人的领导没有任何帮助。不要追随善良领袖的不同版本。恶人的支配，我全然承受。

没有什么比拥有信仰和尊重的随从更罕见的了。没有什么比无赖当领导更糟糕的。不要表现得像人人敬仰的大人物。掌握卑微的谦逊方面。

(14)

如果你处于恐惧之中，控制自己。不要依赖别人自己的意志。善行应该给自己和他人。心里不要有染污，保持纯净。

你是世界上最卑微的人。嫉妒和与有才能的人竞争，同时对自己的缺点毫不羞愧，是一种错误。

(15)

我希望能够掌握力量；不要从贪欲中偏离；依靠意志行事；没有惧怕的数字。

不要从内心深处因为对外表——感官对象——的渴望而反转 不要通过假装渴望受尊敬来欺骗外行人

(16)

我所听闻的教法，是无法被怀疑的。在真理的光辉中，它是不可动摇的；在显现的真理面前，它没有任何夸大。

除非你对佛陀所教的经咒有信念，否则不要自以为是，通过执着于术语和文字而自我迷惑。

(17)

从没有的地方出生；从来没有回头；不作美好的事；逐步出现数字。

从无始以来根深蒂固的误解不会一下子被丢弃，所以不要期望太快达到卓越——要逐步培养你的心智。

( 18 )

具有善良意愿的人，渴望长寿的人，以及希望智慧的人，所有佛法都是数不尽的。

为了竞争而学习，为了名声而当老师，带着想要博学的自豪说话：墨——这三者能成为法吗？

( 19 )

不要依赖自己。对他人讲话没有益处。即使对自己，也没有特别的功德；依靠它，佛法也不能保持。

教别人尚未在自己心中生起的东西是没有益处的。你应该感到羞愧，所以不要为了利益而贩卖真实的法。

(20)

通过布施而得到的功德，由于修行佛法而增加；施与他人功德，甚至都是无量的。

并非真正对世界感到疲惫，你将八种忧虑放在心中，并向他人假装放弃——不要抱怨这么多。

(21)

谨慎地依附，我。哦，不去。向别人施加的善行。对于自己的一切行为数字。

你的口中充满信心；但内心却很少。当你以为自己会有所作为时，你已经老了。你行动快，但成熟慢。反思自己感到厌恶。

( 22 )

火的本性是热的。众生本性如是。不要投向他人。放在自己那里就好。

正如火的本性是热的，众生的本性是有缺点的。与其考虑别人的缺点，不如考虑自己的并放下它们。

( 23 )

大乘的本性不存在；行者不了解世间的道路；不知内心的真实意愿；在本性上无别。

大乘导师的行为在外表上可能看起来不那么好，但你不知道他们内心的想法，所以不要思考导师的过错。

( 24 )

对心灵有何用？对世事有何用？对自己的誓言有何用？对烦恼之心有何用？

你脑中的任何想法对佛陀的智慧来说都是清晰而不被遮蔽的。不要让会冒犯或搅扰本尊的坏念在你心中滋生。

( 25 )

当我看到它的时候，我的心充满了勇气和坚定。我看到了无所畏惧，不受污染的智慧。

就像盲人中的有视力的人一样，佛陀和菩萨总是以清明的眼光观察。不要在私下里行为不端。

( 26 )

每个人都有自己的困难。 我们不能仅凭表象看待价值。 透过外表，看见的是内在。 一个地方消失，便有另一个地方出现。

普通人很难取悦。他们基于熟悉，而不是你的优点，会看到你的缺点并批评你。独自修炼。

( 27 )

这个房子的父亲，这位邻居，所有的手，如果没有强大的存在，在世界上，无论如何在心中都是无尽的数目。

今生的所有父母、子女、侄子侄女、堂兄弟姐妹和亲戚，就像旅客来到又离开旅馆。在你自己的心中，不要感到有关系。

( 28 )

手指放在桌子上。然后，什么也没有发生。手没有被折断。请把它放回给我。

当你两手空空、赤裸、穷困而离开时，你仍会留下东西。不要通过做错事来获取东西。从内心深处，努力去乞求。

(29)

我有一个邪恶的想法。权力无常。无意义的想法没有结果。很高兴见到你，寺庙里的僧人们。

你无力永远停留在你建造的高楼里，所以不要做无意义的建筑工作。留在山间隐居吧。

( 30 )

没有食物的时候怎么办呢？不需要担心，从我这里来吧。我自己不需要。不要伤害别人，我不会拿的。

当未婚者结婚时，他们不需要的孩子就会出生；他们将不得不成为无耻的乞丐。不要听从结婚的坏建议。

( 31 )

对于贪欲的人来说，没有什么工作是必要的。贪欲意志和思想是带来痛苦的起因。

无欲的大能者 无需业印。当心与欲望交织时，业印将引导你堕入低等境界。

( 32 )

不是法的 痴迷和意志的 行为； 我们不会被低劣的恶行所迷惑； 在高贵的境地中保持坚韧； 由获得的功德数来衡量。

不要看低等人的坏榜样，即不善行为的原因。相反，要将他们视为值得同情的人，并追随大成就者的足迹。

( 33 )

佛教的教义方法是显现的。智慧者有能力和德行。通过修行而超越生死。愿你得到圣洁的智慧瞬间。

巧妙地放弃消极的朋友。跟随拥有学识和令人尊敬品质的崇高精神朋友，他们已经舍弃了尘世。

( 34 )

智慧增长的心意，珍贵的财富；依靠自己的心地与行为；以及至高无上的至尊；数量有限，最为美好。

就像一颗能够实现愿望的宝石一样，祝福源自你内心的尊敬。要对神祇、导师和三宝怀有虔诚的敬意。

( 35 )

我没有走邪道；依靠善人的教诲；遵循善行的教导；从佛陀那里学习数字。

导师们，精神上的朋友们，指引你走上明确无误的道路。将他们所教授的指示，融入你的修行核心。

( 36 )

在这个世界上，我很好。对于未知的挑战，我会努力。在自己家园里，一切都会好起来。

通过用智慧学习佛陀教义的宝库，解脱无知和疑惑。在年轻时就努力学习。

( 37 )

如果智慧的朋友不持戒，就会因为恶行而堕落。通过正确的智慧和明确的理解，通过思考和反省，就会获得启示。

如果你没有一个伟大的朋友来关心你，就像劣质的陶罐从底部漏水一样，你的心智容易健忘，所以要通过反思你所听到的来守护它。

( 38 )

懒惰的人无法得到土地；勤劳的人是真正宝贵的；依靠自己去计算；我带着清净的心去做一些事情。

用你所有的力量，保持干净无污，珍贵的修炼纪律——获得宝贵人身的原因。

( 39 )

智慧会带来伤害；愚昧的人会陷入苦难。所有的邪恶行为都是起因于贪婪和无知。

它们会扰乱心智，损害身体。它们被有学问和值得尊敬的人所谴责。它们是一切错误的根源——戒除酒精和性。

( 40 )

没有贪欲的人，如果有坚定的善意意志，凭借意志的力量，就能在法的界限中获得自由。

当你对弟子中的女性感到过于热心时，伪装成同情的欲望可能会为法道制造障碍。

( 41 )

我有一种强烈的欲望，想要克服所有的烦恼。无论恐惧还是痛苦，我都想面对它们。我想要体验清晰的觉知。

要征服那些为你制造痛苦的敌人，不要害怕或气馁。唤起自信的自豪感。

( 42 )

他生病的药剂。带来邪恶的驱除方法。佛法的艰难之处。人们因恐惧而不作弊。

正如流血和烧灼是治疗内病的方法一样，严厉的戒律是治疗下界痛苦的手段。不要太娇嫩和害怕。

( 43 )

这个也是属于什么呢？ 我不会去容忍它。 对于恶意的行为呢？ 禁止它们的年份。

如果你无法忍受现在这样的痛苦，那么你希望忍受三恶道的痛苦就是一种幻想。

( 44 )

这是我的愿望。如果没有得到珍贵的土地，那么得到佛法是有益的。至高无上的年份。

如果你不通过你现在的行为获得宝贵的人身，那么抱着希望成佛的高尚愿望就是错误的。

(45)

懒惰的人没有宝贵的财富；很难获得的成就不能强行得到；没有坚持就无法获得成果；只有坚持不懈才能最终成功。

你已经获得了难得的东西——拥有闲暇和资源的宝贵人身。不要让你拥有的东西消失——种下永恒的作物。

(46)

对别人行善的时候，要心中快乐。如果不想做，就一句话也不要说。

沉思别人所做的美德而心生欢喜。如果你有做不该做之事的冲动，要约束你的身体和言语的动作。

( 47 )

自他二者之间消失。像最尊贵的真实一样。到达不可动摇的目标。无痕数量地出现。

无上的和普遍的成就之源，它可以消除你自己和他人的障碍。在修持本尊时，要毫无怀疑地努力精进。

(48)

这颗心的本性是什么？我在世间的行为是什么？我如何带来痛苦，我如何承受痛苦？通过冥想，我达到宁静。

一旦心中的醉象被从错误的对象中拉开，贪欲的狂风将会吹起，因此用正念的绳索来牵住它。

( 49 )

听者的席位上，充满了惧怕的军队和艰难。 由伟大的思考者进行。 通过闪亮的智慧辨别真理。

用词与聆听组成的低矮房屋很难抵挡虚构的军队。要建造确定性的高塔，就必须在沉思和冥想中努力奋斗。

( 50 )

从一个人的行为来看，有很大的差异。因此，这很困难。没有固定的标准或数字。

借助人船从痛苦的大河中解放自己。这种船很难再得到。既然你已经得到了它，就不要懒惰。

( 51 )

积累罪孽，带来痛苦；因强大的恶意而遭受；没有一个人是无过的；没有人是数量众多的。

建成的会倒塌，积聚的会留下。你将离开亲近的亲人 独自一人去，但谁知道去哪里——旅者不应计划太多。

( 52 )

没有死亡的地方，没有朋友。即使确定会死，也会死。死亡对我没有好处。无所依靠的时候，稍微坚持一下吧。

没有一个地方你可以待而不死。死亡是必然的，并且很快就会到来。当你死时，没有什么能帮助你。始终保持紧迫感。

( 53 )

坚定的信念与幸福，以及远离恶意的双重保障；保持自律；思考后我得出一些结论。

现在你必须在更高境界的持久快乐与下界的痛苦之间做出选择。认真思考这个问题。

( 54 )

工作是劳累的，和什么呢？不懈的努力从事业的起点开始，所有的恶行都会最终消失。

卑劣的行为，如欺诈、欺骗、作弊、撒谎和夺取未被给予的东西，会导致下界的痛苦。放弃坏行为和不当行为。

( 55 )

这一刻的安宁，就像是现在的微风。如果想要稳定的幸福，就让自己内心拥有力量，并给予其他所有众生善意。

生活的乐趣是短暂的。如果你想要持久的幸福，当你有能力完成某件事时，应努力追求像慷慨这样的美德。

( 56 )

一切都是空的。没有固定的自性。诸佛和众生不离于空。它们显现为某种形式的数字。

一切都是幻象的欺骗。除了三宝，没有什么是，如果你信任它，就不会欺骗你的，所以要常常归依。

( 57 )

轮回中没有安乐；人与苦难相伴；做什么都得不到满足；轮回的烦恼无边无际。

轮回中的众生没有幸福。三苦八苦，如癌症，折磨人们。冥想轮回的缺陷。

( 58 )

接近什么呢？源于本性和烦恼的，自己没有的道路，我所知道的。安宁的美德，诸多的标记。

执着是痛苦的根源。通过无私之道舍弃业力和烦恼。培养平和与幸福的品质。

( 59 )

以自己的意思行事。以智慧和知识行事。不要贪图邪恶的事物。今天就做正确的事情吧。

因为愤怒，你放弃了自己的目标，使朋友和亲人伤心。不要抛出毒箭、粗言；放弃你的恶性——仇恨。

( 60 )

想要幸福的人不希望带来痛苦。自己与众生因为无明而受苦。对自己的减少施加限制，对他人的消除施加限制。

你和其他众生在渴望快乐和不渴望痛苦上是相同的。从你自己的经验中推演；冥想你和他人是平等的。

( 61 )

天穹如纸，广阔无边；智慧充满诸世界，有情众生；我以慈悲心，为有害之心的众生；普遍利益所有众生的数字数量。

对于三界中的善良众生，谁曾是你前世的父母，放弃一切恶意和敌意，培养慈爱和同情心。

(62)

众生会遭受痛苦吗？如同一母同胞一样。我们手中没有任何办法去改变吗？

当你对有感知的生物造成伤害时，有同情心的胜利者会感到就像他们唯一的孩子被杀害的父母一样。这绝不可能让他们感到高兴。

( 63 )

轮回的工作是什么呢？从业和烦恼中来的我呢？即使如此，我也从自我工作的过程中来吗？为无我之意，也有一些数字吗？

轮回中的一切痛苦都源于因——业力和烦恼。这些源于对自我的执念，所以要观照无我。

( 64 )

与两者相比，我内心充满了欲望和执着。

没有抓捕者和被抓捕者，你自己的心从未显现。它超越了理智的范畴，所以你必须摆脱一切欲望。

( 65 )

首先我想说，如果有明显的差别就没有问题。我不会对错误的人生气。我会从错误的地方学习。

初学者的觉悟是清晰的，但它没有稳定性。不要把它抛到思绪的风中；用正念的绳索去抓住它。

( 66 )

无论出生为何，都是因为缘起。 在四方之间停留，无有智慧，依止意志中行。

任何本性都无法确立，因此它本质上无四边极。在其中，也无法生起任何心，因此要无任何执取者的念头。

( 67 )

在佛法的道路上，没有真实的存在。对于我本身而言，也没有真实的存在。显然，也没有什么可执着的。

现象都像梦和幻觉。根本没有真实的东西。不要对那些虽出现却不存在的事物过分执着。

( 68 )

我不对具体情况感兴趣。遵守法律规定。不要参与非法活动。请向有关人员求助。

就像梦中的因果，虽然在现实本性中并未确立，但混乱之人的业力和结果是不会失败的——放弃恶行，努力行善。

( 69 )

我向老师祈祷。我献上我的身体和意志。我赠送心意。我向善良的朋友致敬。

对你过去的过错心怀悔意，从现在起，避免重蹈覆辙，即使这会付出生命的代价。始终努力追求解药，依止于庇护和菩提心的美德。

( 70 )

作为一名真正的修行者，我也是一样。我以无尽的慈悲对待所有众生。对一切大地上的众生，我以闪亮的心意显露出来。

即使是一个试图作善的行为，也会产生取之不尽的结果。在三世的一切奉献之前，都要以菩提心的决心为先。

( 71 )

在这里，如果没有痛苦和苦难； 痛苦来自何处呢？ 根据情况显现出极高的境界； 人的幸福是真实可见的。

如果你的心与这些建议和谐一致，你将从下界的所有痛苦中解脱出来，并且在短期内，你将获得天界和人类的享乐。

( 72 )

最终，二者——我和他； 四大智；超越轮回的二者，不存在的我与他。

最终你将净化两种障碍，并拥有三身和四智。你将达到既不住于轮回也不住于涅槃的无上觉悟。

据说纯洁的嘴巴，如果我把它写在口头的经文上，就是两种方式。
