摘要 人类学家和宗教学者长期以来一直在讨论东南亚社会中教义上的上座部佛教、所谓的“万物有灵论”以及其他民间习俗之间的关系。基于民族志证据，已经提出了多种有关这种关系的模型。我们首次使用为此开发的新量表——缅甸佛教宗教性量表，对这些竞争模型进行了心理测量和定量评估。在我们的第一项研究（n = 2285）中测试了现有假设后，我们提出了一个替代模型，并在第二项研究（n = 3377）中对其进行了测试。我们认为，该模型支持“大传统”和“小传统”之间的二维区分，为长达数十年的理论争论提供了启示。文人跨国宗教传统与当地多样化宗教实践并非冲突，而似乎在宗教性的两个互补维度中得到了体现。这一区分在心理测量研究中迄今被忽视，但可以说在佛教之外、在更广泛的宗教心理学研究中也值得关注。我们的研究结果表明，如果宗教性研究依赖于贬低小传统为纯粹迷信的教义声明，它可能会忽视宗教生活中的一个关键维度。

1.1 上座部佛教的概念 上座部佛教虽然缺乏单一、集中的权威，但作为一种主要在东南亚和斯里兰卡广泛实践的佛教形式，它呈现为一个跨国宗教共同体，其特征是人员、文本和思想的持续流动与交流 [6]。这导致了上座部僧侣和其他专家实践者在整体宇宙观和价值体系上的某种程度的一致性。特别是，从18世纪末开始，但在20世纪中期显著加速，上座部佛教见证了一些“复兴主义”或“新教主义”[7–9]运动的传播，这些运动提倡宗教的纯化形式，包括大众禅修、居士经文学习，以及表面上回归简朴、务实的佛教形式，常被呈现为“科学的”或“现代的”[10]。虽然这些运动可能反映了长期以来对佛教社区持续衰落的关注，因此不一定能被视为殖民主义导致的简单断裂[11,12]，但它们仍与20世纪的政治议题紧密交织，并被采纳为从缅甸到斯里兰卡的民族主义意识形态核心，其中后殖民国家将自己呈现为正统佛教的代表和保护者[13–15]。与此同时，跨国的上座部佛教教义与各种地方性习俗和信仰并存，包括各种形式的精灵、半神、巫师和炼金术士，以及魔法和占卜。这些元素远不仅仅被佛教容忍，通常高度融入佛教体系，在佛塔中占有神龛空间，并在关于佛陀生平的神话记载中被提及。然而，官方宗教，尤其是在其“复兴主义”形式中，通常对这些元素漠不关心，在最坏情况下，将其视为愚昧怀着的异教时代遗留物，仅因平信徒的无知而依旧存在[16]。
在这种不稳定的关系中，教义常常断言，尽管佛教是一种“宗教”（在缅甸，这一概念仅在19世纪殖民时期被引入[17]），本地元素只是“传统”——并无特别重要性的文化瞬间现象。外部观察者长期以来一直在争论如何最好地理解这双方的关系，并且在这样做的过程中，显然受到了现代上座部佛教自身偏重贬低本地习俗以支持教义正统的影响[18]。在缅甸，殖民学者倾向于认为佛教和所谓的“泛灵论”或围绕对当地神灵那特（nats）的祭祀而形成的民间宗教，是两种截然不同的宗教；而佛教在未能成功取代较早的泛灵论宗教后，对大多数民众而言，仅仅是在泛灵论上的“薄薄一层涂饰”[19]。确实，这两种宗教常被视为直接冲突；泛灵论是

1.2 宗教虔诚的心理测量 宗教心理学提供了一个新的视角来审视这些问题。与其将宗教作为一种文化系统来研究，心理学更倾向于将灵性、宗教虔诚或宗教取向作为个体特征进行研究。个体的宗教虔诚并不等同于可能被认为构成“宗教”的机构、社会结构和共享意义，事实上，批评者曾认为宗教心理学可能过于狭隘地关注个体特征 [36]。尽管如此，对宗教系统的个体取向仍可能提供对宗教系统本身性质的有价值见解——尤其是因为如果存在多种宗教系统，个体可能会表现出对每种宗教系统不同的取向。因此，对宗教虔诚的心理测量评估为解决社会和文化争论提供了一种新颖的个体层面工具。然而，测量宗教虔诚的方法仍有不足。一般而言，心理测量学的稳健领域可望围绕与感兴趣构念对应的一组公认测量方法达成一致。另一方面，宗教虔诚量表在几十年间持续增加，Hill 和 Hood [37] 所记录的已有 126 种，自那以后还有更多新增 [38]。一方面，这源于研究者的不同兴趣——从宗教承诺水平，到对上帝的态度，再到将宗教作为应对机制的使用。另一方面，缺乏公认的理论框架阻碍了对测量对象性质的共识 [39]。大量理论关注集中于宗教虔诚是否具有普遍的潜在结构。Allport [40,41] 认为，个体处于内在型与外在型宗教取向的光谱上，内在型关心精神追求本身，而外在型则关注通过宗教获得其他利益，如社会地位。

通过构建这样一个包容性的量表，我们旨在利用因子分析揭示缅甸佛教虔诚的潜在结构，从而评估上述1.1节中概述的该结构的竞争模型——首先检验关于该宗教是否构成一个或两个系统的说法；其次检验如果存在多个宗教系统，这些系统是互补的还是冲突的说法。

2. 量表建设与试验研究 缅甸佛教宗教性量表（BBRS）的构建遵循了两个标准：首先，它应包含反映缅甸各种宗教形式的条目，包括教义佛教、纳特信仰、占星术和伟扎派；其次，它应能够捕捉跨文化已识别出的宗教性的多个广泛维度。为此，我们改编了五维的宗教中心性量表（CRS），这是一个为跨文化和跨宗教研究设计的工具，能够捕捉心理测量文献中的多个关键区分，并且已在25个国家超过100项研究中使用[56]。对于CRS的每一个维度，尽可能包括反映教义佛教、纳特祭祀和伟扎派的条目。总共使用了30个条目，包括21个频率条目、3个兴趣条目、4个信念条目和2个外在条目（见表1）。BBRS的初稿由专业翻译人员翻译成缅甸语，并进行了回译为英语。2017年6月在仰光对信息提供者进行了访谈，从而进一步调整量表条目。2017年8月进行了在线试验研究（n = 456）。通过Facebook收集的参与者反馈表明翻译质量实际上很差。在与另外两位翻译人员协作后，制作了修订版本，并于2017年9月在网上进行了试验（n = 2283）。这次反馈显示翻译问题减少。随后再次咨询翻译人员，制作了BBRS的最终缅甸语版本。为了评估BBRS与专为上座部教义设计的测量工具之间的关系，还将Thanissaro的佛教态度量表（TSAB）[47]翻译成缅甸语，并采用相同方式进行了验证。

3. 研究1 与其提出单一假设，我们着手测试多个相互竞争的假设，这些假设对应于上文1.1中概述的人类学争论的各个方面。竞争的假设如下：

A. 单一系统：教义南传上座部佛教、纳特（Nat）崇拜、维克萨（Weikza）信仰和占星术形成一个单一、整合的宗教系统。因此，个体的宗教性由一个单一的一维结构构成。

B. 两个对立系统：佛教，包括维克萨实践和占星术，以及纳特崇拜，形成两个独立且相互冲突的系统。因此，宗教性最好用一个两因素的模型来表述，这两个因素呈负相关。

C. 两个互补系统：佛教，包括维克萨实践和占星术，以及纳特崇拜，形成两个独立但互补的系统。因此，宗教性最好用一个两因素的模型来表述，这两个因素呈正相关。

CFA、EFA 和 SEM 分析均在 Mplus 8 [59] 中进行。所有分析均使用根据 2014 年缅甸人口普查 [57] 的年龄和性别分布计算的样本权重进行。权重使用 R 的 anesrake 包生成 [60]，采用推荐参数 [61,62]。CFA 和 EFA 的计算均使用加权最小二乘法（带均值和方差调整的卡方，WLSMV）。在所有模型中，Likert 量表均被视为有序变量。以下报告比较拟合指数（CFI）和均方根误差近似（RMSEA），一般接受的经验法则是 CFI ≥ 0.95 和 RMSEA ≤ 0.06 表示模型拟合良好 [63]。

3.2.1 验证性因子分析
包括所有条目的单因子 CFA 模型显示拟合较差（CFI = .766，RMSEA = .092；χ2 (405, N = 2285) = 8183.090, p < 0.001；TLI = .749），因此我们拒绝了单一单极结构假设 (A)。为了检验剩余的两个假设，即佛教与万物有灵论代表两个系统，要么冲突（假设 B），要么互补（假设 C），拟合了一个双因子模型，将与 nat 相关的条目加载到一个因子上，所有其他条目（包括 weikza 条目）加载到另一个因子上。该模型同样显示拟合较差（CFI = .764；RMSEA = .093；χ2 (404, N = 2285) = 8406.616, p < 0.001；TLI = .746）。这些假设的另一种版本是放宽 weikza 邪教属于“佛教”的假设。为了检验这一点，拟合了三因子模型，将佛教、万物有灵论和 weikza 条目分开；该模型仍不理想（CFI = .885；RMSEA = .065；χ2 (403, N = 2285) = 4324.228, p < 0.001；TLI = .875）。因此，假设 (B) 和 (C) 被拒绝。

5.3 结论 

虽然本研究考察了缅甸佛教的宗教性，但文献中的大多数讨论并非集中于宗教性本身，而是集中于宗教。我们并不认为宗教这一概念容易被明确定义，或者说它必然具有分析上的实用性。不能理所当然地认为，个人宗教性与可能被标记为“宗教”的社会和文化系统之间的关系是清晰或显而易见的。然而，可以说两者之间必须存在某种关系；例如，如果佛教和万物有灵论构成两个不同的宗教系统，我们可能会预期个人对这两个系统的认同在不同维度上有所差异。因此，尽管我们的发现最终未能在缅甸宗教本身的理论观点之间做出裁决，但它们确实表明可能需要一个新的概念框架。 

更广泛地说，我们的研究结果表明，对于宗教性测量来说，测试“大传统”和“小传统”形式的宗教性可能是有益的。不仅在上座部佛教社会中，在其他宗教传统中，仅关注大传统的宗教性测量都有忽视宗教体系关键要素的风险。鉴于小传统的地域特异性，这类测量方法必然需要根据具体背景进行仔细调整，但这种测量方法的发展将使我们能够评估在缅甸环境中发现的意外正交性是否具有更普遍的适用性，确实也可以在不排除宗教性最核心组成部分的情况下进行评估：即对宗教作为一种活生生的、在本地实现的实践体系的取向。
