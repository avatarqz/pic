所有美国人都受到日益加剧的政治两极分化的影响，无论是因为陷入僵局的国会还是充满敌意的节日家庭聚会。人们认为事实对于赢得政治对手的尊重至关重要，但我们的研究表明这种信念是错误的。我们发现，分享关于政治问题的个人经历——尤其是涉及伤害的经历——有助于通过提升理性认知来促进尊重。这项研究为增加道德理解和减少政治不宽容提供了一条直接途径。这些发现也引发了关于科学和社会在“假新闻”时代应如何理解真相本质的问题。在道德和政治分歧中，普通人往往将主观经历视为比客观事实更真实。

美国的政治敌意极高（1），自由派和保守派经常互相不尊重和妖魔化对方（2, 3）。在当今政治中，无论是当选官员（4）还是普通人（5），都不愿意与政治对手进行交流。这种政治不宽容破坏了公开讨论和辩论——这是公民制度的基石（6）——并可能使我们忽视政治对手的共同人性（7）。是否有办法在政治分歧中增加尊重？过去的研究揭示了若干可能的策略来缓解群体间的不宽容，例如强调超越性的目标（8）或提供群体间接触（9）。然而，这些策略难以实施，因为它们需要对手之间的反复积极互动；与外群体成员的一次性互动往往会导致更多的不宽容，而不是减少（10）。在现代美国，创造多次积极的跨政治互动机会尤其具有挑战性，因为保守派和自由派生活在不同的社区（11），且共处时间越来越少（12）。在这里，我们探讨即使是一次性互动如何也可能促进政治对手之间的尊重。我们认为，增加对对手理性的认知可能有助于弥合政治分歧，我们将其定义为对持有相反政治观点的人培养尊重。几十年的研究强调了外群体敌意与将外群体成员视为无意识或非理性之间的联系（13）。那些不同意我们坚信的观点的人往往看起来像被洗脑或无知（14），这也解释了为什么与政治对手的讨论常常显得无效（15）。增加

### 心理与认知科学

自由派和保守派都认为在政治讨论中使用事实有助于促进相互尊重，但15项涵盖多种方法和议题的研究表明，这种信念是错误的。政治对手在道德信念得到个人经历支持时，会比仅有事实支持时更尊重对方。个人经历的尊重效力在各种政治议题的问卷调查研究、一项关于枪支对话的实地研究、对堕胎相关意见视频的YouTube评论分析以及对137份福克斯新闻和CNN采访记录的档案分析中得到了体现。最能够赢得对手尊重的个人经历是与议题相关并涉及伤害的经历。中介分析显示，这些与伤害相关的个人经历通过提升理性认知来增加尊重：即使是持不同枪支、税收、移民和环境信念的人，也能理解避免伤害是理性的。研究表明，在非道德分歧中，人们会相信事实和个人经历的真实性；然而在道德分歧中，主观经历似乎更真实（即较少受到怀疑）而不是客观事实。这些结果具体展示了如何弥合道德分歧，同时也揭示了我们的直觉如何可能误导我们。追溯到启蒙时代，哲学家和科学家在追求真理时一直把客观事实置于经历之上。然而，在道德分歧中，通过分享主观经历而非提供事实，更能有效地传递真实性的感知。

尽管这两种结果确实相关——劝说通常需要建立在相互尊重的基础上（51）——但这些概念并不完全相同；人们可以尊重他人而不认同其道德信念。也就是说，劝说往往是政治讨论的一个目标（52），但一些学者认为，当我们首先专注于建立相互尊重时，政治话语的效果最好（53, 54）。当然，即使目标是建立Kubín等人的……

尊重，试图说服他人是人类天性的一部分 (55)，但道德信念极难改变 (56)。在这里，我们不讨论说服的问题，而是专注于如何在与政治对手的道德分歧中最好地培养尊重。测试核心模型：从个人经历到感知理性再到尊重 在政治分歧中，将个人的道德信念建立在个人经历上比建立在事实基础上更能促进尊重吗？这种影响是否通过对理性的感知产生？在对图 3 中概述的核心模型的首次测试（研究 4，n = 177）中，参与者报告了他们在税收、煤炭和枪支政策上的立场，然后阅读了持不同观点的人——这些观点不同可能是由于个人经历（例如，由于新的煤炭法规而失业）或事实知识（例如，通过阅读相关主题学到的事实）。然后，参与者对对手的理性程度进行评分（例如，“坚持其立场是合乎逻辑的”）、他们愿意尊重对手的程度（例如，“考虑这个人的观点”），以及他们愿意与对手互动的程度（例如，“与此人交换意见”）†。结果显示，基于个人经历的立场比基于事实的立场更能增加感知理性（M = 4.78, SD = 1.26 vs. M = 4.13, SD = 1.29, t(175) = 0.02, P = 0.001, d = 0.51）。个人经历也比事实更能促进尊重（M = 4.90, SD = 1.17 vs. 事实 M = 4.46, SD = 1.15; t(175) = 0.23, P = 0.01, d = 0.38）。如预测的那样，感知理性在个人经历（相对于事实）与尊重之间发挥中介作用（间接效应 = 0.48, SE = 0.14, 95% CI [0.20, 0.78]）。我们注意到，通过理性/尊重，从个人经历到互动意愿的间接效应在每项研究中都是显著的（补充信息附录）。然而，在正文中，我们仅报告当个人经历对互动意愿具有显著总体效应时的结果。我们的数据的荟萃分析（在论文末尾附近呈现）揭示了显著的总体效应†。

第7项研究（n = 273）测试了个人经历是否需要与分歧主题相关才能促进尊重。我们的数据表明，对理性的感知对尊重至关重要，因此相关性可能也很重要——将你的道德/政治信念建立在无关的个人经历上似乎是不理性的（例如，我支持持枪权，因为我受到企业税收政策的伤害）。另一方面，也可能仅仅存在任何个人痛苦就能增加尊重。在这项情境研究中，参与者对基于有关枪支的相关事实、与枪支相关的个人经历或无关的个人经历（即生意破产）的对立观点进行了评价。结果显示，与事实（理性：M = 3.74, SD = 1.40, P < 0.001；尊重：M = 4.40, SD = 1.34, P < 0.001）和无关个人经历（理性：M = 3.60, SD = 1.42, P < 0.001；尊重：M = 4.29, SD = 1.41, P < 0.001）相比，相关的个人经历在增加感知理性（M = 4.86, SD = 1.60）和尊重（M = 5.19, SD = 1.26）方面明显更有效。事实与无关个人经历之间没有显著差异。这些结果表明，个人经历需要与当前问题相关，才能促进对立双方的尊重。第8项研究（n = 255）测试了个人经历是否应涉及伤害，以最佳方式促进政治对手的尊重。这项情境研究比较了基于伤害的个人经历（例如，用枪保护家人免受入侵）、非伤害个人经历（例如，上过枪械安全课程）或事实的对立者评价。结果显示，与非伤害个人经历（理性：M = 4.09, SD = 1.57, P < 0.001；尊重：M = 4.55, SD = 1.41, P < 0.001）相比，基于伤害的个人经历在增加感知理性（M = 5.00, SD = 1.42）和尊重（M = 5.34, SD = 1.21）方面更为有效。

在许多研究中，基于个人经验（而非事实）形成立场似乎让人在对手看来更理性。我们认为这一效果的原因在于个人经验是不可质疑的；亲身经历的痛苦可能相对不易受到怀疑。尽管真理的本质似乎是客观的，研究显示其感知会受到外部因素的影响（57）。下一项研究考察了个人经验与事实的“真理感知”。从技术上讲，事实可能是“客观”的，但在现代社会中，总有人可以用另一个事实反驳一个事实，从而使事实容易受到怀疑。相比之下，个人经验可能更难受到质疑，特别是在道德领域，主观信念似乎具有客观性（58）。如果个人经验被视为“更真实”且不易被怀疑，这有助于解释为何个人经验会增加被感知的理性——主观来说，遭受伤害的个人经验实际上更“客观”。

当然，这项工作存在局限性。我们承认，这些研究往往使用来自在线样本的自我报告数据；然而，该研究也包括了社交媒体和传统媒体的档案分析、与社区成员的行为研究以及具有代表性的样本。关于这些结果是否具有跨文化适用性仍是一个开放的问题，但我们建议，即便是在一个政治上分裂的国家，提高公民之间的尊重也是可能有用的。未来的研究应考察这些结果的调节因素，继续探讨经验的真实性是否取决于分享者的身份。长期以来，属于种族和性少数群体的人的经历常常被怀疑会阻碍社会变革。尽管我们的小情境中的目标个体在种族和性别上有所不同（见研究14），但我们并没有特别测试性别歧视或种族歧视的个人经历是否比事实更能促进尊重。然而，值得注意的是，强大的社会变革运动（例如，#MeToo、#BlackInTheIvory）在很大程度上依赖于分享个人经历。此外，我们也没有测试在缺乏强烈先入为主观念的情况下，了解个人经历（而非事实）在促进尊重方面是更有效还是更无效。花较少时间思考某个问题的人可能对事实不那么怀疑，但另一方面，对问题不太关心的人也可能仍然觉得个人叙述有吸引力。在本文中，我们将事实和个人经历对立地作为两种策略进行对比，这与长期以来的哲学（63）和科学讨论（64）关于认识论的讨论一致。事实与个人经历之间的紧张关系也在我们的数据中通过它们的负相关（例如，研究12）表现出来。然而，最有成效的讨论可能涉及个人经历与事实的某种结合。我们推测，个人经历可以在对话初期使用，以首先建立相互尊重的基础，然后在对话转向政策具体内容时引入事实。
这些研究考察了普通美国人，目前尚不清楚分享个人经历的好处是否也适用于当选官员之间的互动，或者是否能提升他们实施的政策质量。事实对于制定政策解决方案当然很重要，但要创造有效的两党解决方案，需要政治对手共同合作，而与一个你尊重的人合作会更容易——正如最近旨在弥合政治分歧的倡议所示（65）。提供相关的个人经历也可能是建立政策制定者间尊重的有效策略，因为他们在认可对方事实的有效性之前，可能需要先建立共同的理解。
