# 名色（nāmarūpa）经文梳理

> 依据资料：本地巴利语料库（chaṭṭha saṅgāyana CSCD：《相应部》12 s0302、《长部》s0102、《分别论》及注疏 Sammohavinodanī abh02）逐条提取；CBETA 电子佛典（《长阿含》《中阿含》《杂阿含》《法蕴足论》《大般涅槃经》）检索核对；和辻哲郎《原始佛教的实践哲学》第二章「緣起説」（OCR 全文，名色节为其核心章）；印顺《佛法概论》；木村泰贤、Rhys Davids、Walleser、赤沼诸说转引自和辻原注。本梳理重点：①名色在经论中的诸定义与诸形态；②《大缘经》DN 15 解释"名色缘触"的四词表 **ākāra / liṅga / nimitta / uddesa** 的区别及各本翻译。

## 一、"名色"的定义：五种文本、四种配方

| 文本 | 名（nāma） | 色（rūpa） | 备注 |
|---|---|---|---|
| **SN 12.2《义说经》**（≪《杂阿含》系统） | 受、想、**行(思 cetanā)**、触、**作意**（五法，**不含识**） | 四大＋四大所造 | 原文："Vedanā, saññā, cetanā, phasso, manasikāro – idaṃ vuccati nāmaṃ"；印顺《佛法概论》即据此译作"受、想、心、触、作意，是谓名" |
| **《分别论》Vibhaṅga**（论藏） | 受、想、行**三蕴** | 四大＋四大所造 | "Vedanākkhandho, saññākkhandho, saṅkhārakkhandho"；同样不含识——识在缘起链中是名的**因**，不可入名 |
| **《杂阿含》卷 13 经 306** | 识＋受、想、思＝"四无色阴" | **根＋境**（"眼色"） | "触俱生受、想、思，此四无色阴、眼、色，此等法名为人"——在六处缘触的语境中定义，色含根境 |
| **《法蕴足论》卷 12**（说一切有部） | 所生受想行识（含识） | ①根＋境（"此中眼及色，名为色"）；②胎生语境：羯剌蓝（kalala）自体；③业趣语境：身语业行为 | 同一部论按语境给出三套"色"——最显示有部的"随宜安立" |
| **《增壹阿含经》**（T02n0125） | — | "四大及四大所造色，是谓名为色" | 色定义同巴利系统 |

**要点**：
1. **"名"的核心是受想行＋触、作意等心所法**；巴利两本（SN 12.2、Vibhaṅga）都把**识排除在外**——因为识是名的条件（"缘识有名色"），不能自为其果。汉译《杂阿含》306 与《法蕴足论》则把识纳入"名"（四无色蕴），是**依五蕴结构**的重新配列（和辻指出汉译"名＝四无色蕴（含识）"）。
2. **"色"不限于"物质"**：《法蕴足论》的根境说、业行说表明，在有部用法中"色"可以等于"依报／根境／身语行为"——五蕴说的"色蕴"与缘起链的"名色之色"并不同界（和辻）。
3. 印顺的折中：五支义即具十支——"结所系法"＝十二处、"味着"＝受、"心"＝识，名色可开可合，不必拘泥字形。

## 二、名色在缘起链中的诸形态

| 形态 | 链位 | 代表经 | 功能与要点 |
|---|---|---|---|
| **十二支标准式** | 识→**名色**→六处→触 | SN 12.1–2 ≪《杂阿含》296 | 名色＝个体生存的全体，为六处之缘 |
| **九支式** | 识↔**名色**→触（**省略六入**） | DN 15《大缘经》 | 名色**直接**为触之缘——触的义理由"感官条件"深化为"概念与感性的互为条件"（即四词表所在，见第三节） |
| **十支式** | 识↔**名色**→六处→触 | SN 12.65《城喻经》、SN 12.67《束芦经》、DN 14《大本经》 | "齐识而还，不能过彼"；菩萨成道观的核心（Dessein 专研） |
| **二法式** | （内）识身＋（外）**名色**＝二法，缘二法生触与六内处 | SN 12.19 ≪《杂阿含》294 | "内有识身，外有名色，此二因缘生触"——把"识"与"名色"对举为内外二层的唯一公式 |
| **五支式** | 爱→受→有→生→老死 | 《中阿含·大因经》开首 | 注意"**受→有**"（无取支）——印顺、和辻据此论"五支释本独立，九支释系插合" |
| **施設论式** | 名色施設为"人" | 《杂阿含》306–307、卷 13 335《第一义空经》 | "此等法名为人"；"俗数法者，谓此有故彼有…除俗数法"——名色是"人／众生"概念的安立处 |
| **四食链** | 名色为六处之缘…展转上溯至爱 | SN 12.11–12 ≪《杂阿含》371 | "六处名色因、名色集…"——与四食说结合的链式 |
| **Upanisa 光明链** | 名色为六处之缘…苦→信→…→解脱 | SN 12.23 ≪《增壹阿含》 | 加入道支的还灭展开 |

## 三、识 ↔ 名色互缘：最独特的创见

### 1. SN 12.67《束芦经》(Naḷakalāpīsutta)——舍利弗与摩诃拘絺罗问答

> "Seyyathāpi, āvuso, **dve naḷakalāpiyo** aññamaññaṃ nissāya tiṭṭheyyuṃ. Evameva kho, āvuso, nāmarūpapaccayā viññāṇaṃ; viññāṇapaccayā nāmarūpaṃ…"
> "譬如两束芦苇互相依住而立。如是，名色缘识，识缘名色……"
> 逆观："抽其一束，他束即倒"（ekaṃ ākaḍḍheyya, ekā papateyya）——名色灭则识灭。

- **巴利作"二束"，汉译《杂阿含》288 作"三芦"**："譬如三芦立于空地，展转相依，而得竖立，若去其一，二亦不立，若去其二，一亦不立"（木村、和辻均指出此异；《成唯识论》卷三引作二芦，配阿赖耶识）。
- 意义：识（了别）与名色（被了别的特殊限定）**互为依据**，无第一因——这是各家公认佛陀最独特的创见（木村视为"师独悟"核心；Bodhi 称之为"隐藏的漩涡"）。

### 2. SN 12.65《城喻经》(Nagara)——"齐识而还"

> "Paccudāvattati kho idaṃ viññāṇaṃ nāmarūpamhā **na paraṃ gacchati**. Ettāvatā jāyetha vā jīyetha vā mīyetha vā cavetha vā upapajjetha vā…"
> "此识从名色**退转，不能再超过它**。仅到此范围内，有生、老、死、迁、再生……"

≪《杂阿含》287："我作是思惟时，齐识而还不能过彼，谓缘识名色，缘名色六入处……"＋古城喻＋"我得古仙人道……谓八圣道"。

### 3. DN 15《大缘经》段 115–116——母胎三问与"如是性"结论

**段 115（识缘名色）**：三问答——
1. "识若不入母胎，名色能在胎中成立吗？"——不能。
2. "识若入胎即出，名色能成就'如是性'（itthattāya）吗？"——不能。
3. "若幼小者之识断坏，名色能成长吗？"——不能。

**段 116（名色缘识）＋全经结论**：
> "识若于名色不得住处，未来生老病死苦集能显现吗？"——不能。
> "**Ettāvatā** jāyetha vā jīyetha vā mīyetha vā cavetha vā upapajjetha vā. Ettāvatā adhivacanapatho, ettāvatā niruttipatho, ettāvatā paññattipatho, ettāvatā paññāvacaraṃ, ettāvatā vaṭṭaṃ vattati itthattaṃ paññāpanāya, yadidaṃ nāmarūpaṃ saha viññāṇena aññamaññapaccayatā pavattati."
> "仅到此范围内有生老病死与迁移；仅到此范围内有**语言道、名词道、施設道、智慧领域**；仅到此范围内**流转以显现'如是性'**——即：名色与识以互为缘而流转。"

≪《长阿含·大缘方便经》（T01n0001 卷十）："齐是为语、齐是为应、齐是为限、齐是为演说、齐是为智观、齐是为众生。"

- **和辻的读法**：此段**不是轮回说**（vatta 本义为"圆轮／流转的存在"，非 saṃsāra），而是说：识与名色互缘，只在"语言、名词、施設、智慧"的范围内有"如是性"的显现。把名色解为胎儿、识解为入胎之神识（乾闼婆），是**论藏时代**的胎生学解释（《法蕴足论》卷十二引《教诲莎底经》已如此；和辻详辨）。
- 《法蕴足论》的轮回化读法（引《教诲颇勒窭那经》）："识为食故，后有生起。此识云何？谓**健达缚**（gandharva）……与**羯剌蓝**（kalala）自体和合。此羯剌蓝自体和合，名为色；即彼所生受想行识，名为名"——健达缚（原为神话中的神鸟／香阴）取代"识"成为入胎者，正是和辻所批"通俗灵魂信仰与缘起结合"的论藏标本。

### 4. MN 38《茶啼经》（≪《中阿含》54）——斥"识流转"

Sāti 主张"识流转轮回"（viññāṇaṃ sandhavati saṃsarati），被佛严斥；佛以缘起代之——识非自性流转，而是"名色缘识、识缘名色"的互为缘起。这是"识↔名色互缘"被用来**破灵魂见**的标准场域。

## 四、四词表：ākāra / liṅga / nimitta / uddesa 的区别

### 1. 出处与原文（DN 15《大缘经》，chaṭṭha 段 114；论藏注疏引作 dī. ni. 2.114）

此段是佛对"**名色缘触**"（nāmarūpapaccayā phasso）的解释：

> "'Nāmarūpapaccayā phasso'ti iti kho panetaṃ vuttaṃ… yathā nāmarūpapaccayā phasso. **Yehi, ānanda, ākārehi yehi liṅgehi yehi nimittehi yehi uddesehi nāmakāyassa paññatti hoti**, tesu ākāresu tesu liṅgesu tesu nimittesu tesu uddesesu asati api nu kho **rūpakāye adhivacanasamphasso** paññāyethā"ti? "No hetaṃ, bhante".
> "Yehi… **rūpakāyassa** paññatti hoti… api nu kho **nāmakāye paṭighasamphasso** paññāyethā"ti? "No hetaṃ, bhante".
> "Yehi… **nāmakāyassa ca rūpakāyassa ca** paññatti hoti… api nu kho adhivacanasamphasso vā paṭighasamphasso vā paññāyethā"ti? "No hetaṃ, bhante".
> "Yehi… **nāmarūpassa** paññatti hoti… api nu kho **phasso** paññāyethā"ti? "No hetaṃ, bhante".
> "**Tasmātihānanda, eseva hetu etaṃ nidānaṃ esa samudayo esa paccayo phassassa, yadidaṃ nāmarūpaṃ.**"

**逻辑**：四重"反证法"（reductio）——没有使名身／色身成立的诸项，则增语触、有对触乃至触本身都不能成立；故"触以名色为缘"。

### 2. 四词的分工（不是四个并列范畴，而是同义累积）

| 词 | 训读 | 义涵 | 在例中的意思 |
|---|---|---|---|
| **ākāra**（ākṛti） | **相、貌** | 事物呈现的**样式、面貌** | "花"作为花呈现出来的色形香触之相 |
| **liṅga** | **性、标** | 可据以**识别**其为某类的**标记、性相** | "花"所以区别于叶、干的内在标识 |
| **nimitta** | **相、标志** | 认识所**抓取**的**所缘相** | 心借以把握对象的"相"（想蕴取像性所依） |
| **uddesa** | **指称、指示、陈述** | **指出来、列举、称说**（语言层的指称） | "花"这个名的所指与所称 |

- 四词是 Nikāya 典型的**同义叠加（cumulative synonymia）**，共同回答一个问题：**"名身（nāmakāya）是如何被施設（paññatti，被安立／被指称）的"**。其中 **uddesa（指称）点题**——名色即"被指称者（色）与指称（名）"的关系。
- 和辻的义理发挥：**名＝概念性的把握**（be-greifen；命名即把特殊物象收进一个意义）；**色＝符合名的"无名者"**。"花"之名若与"叶"之名无特殊意义的区别，就不能给予色身任何感觉内容；红绿之物若无特殊相，就不能为名所摄。**名的特殊性与色的特殊性互为条件**——这正是 DN 15.114 的逻辑。

### 3. 各本翻译对照（四词表的流传与缩减）

| 传本 | 对四词表的处理 | 两种触的配搭 |
|---|---|---|
| **巴利 DN 15.20**（段 114） | 四词完整，四重反问 | 名身的施設→色身中的**增语触**（adhivacana-samphassa）；色身的施設→名身中的**有对触**（paṭigha-samphassa） |
| **《长阿含·大缘方便经》**（T01n0001 卷十） | 四词**全省**，作"名色／**形色相貌**" | "若使一切众生无有名色者，宁有**心触**不？""若使一切众生无**形色相貌**者，宁有**身触**不？" |
| **《中阿含·大因经》**（T01n0026 卷廿四） | 四词省为"**所行、所缘**" | "所行所缘有名身…有**有对更乐**耶？""有色身…有**增语更乐**耶？"——名身↔有对、色身↔增语，与巴利**相反**（和辻指出） |
| **《法蕴足论》卷十二**引《大因缘经》 | 四词压缩为一个"**相**" | "若依止此**相**施設名身，此相若无，为可施設**增语触**不？""若依止此相施設色身，此相若无，可施設**有对触**不？"——配搭同巴利 |
| **Sammohavinodanī**（《分别论》注） | 引全四词表（注明出处 dī. ni. 2.114） | 读作"触也单以**名为缘**"（nāmamattapaccayāpi so hoti）之证据——从"法间依存"转向"缘数分析" |

### 4. 两种触（本段的核心概念）

- **增语触** adhivacana-samphassa：adhi-vacana＝"指说、名号"——通过**概念／语言**成立的触（"被称作花"这一层的接触）。
- **有对触** paṭigha-samphassa：**感官对碍性**的触（眼见色、耳闻声的对境冲击）。
- 和辻：二者是**一体的两面**——"花被感受"必同时是"被见与被称说"；没有不被感受的色，也没有不被指称的名。汉译（心触／身触；增语更乐／有对更乐）保存了这组区分，虽配搭偶有颠倒。

## 五、前佛教背景与近代解读

**前佛教用法**（转引自和辻注）：
- 《Satapatha Brāhmaṇa》XI 2.3：名＝语言（vāc），色＝心（manas）——梵的二大示现。
- 《Chāndogya Upaniṣad》VI 3.2：名色为梵的两大示现；VIII 14.1："**空**者，名色之开展者"（ākāśo vai nāma nāmarūpayor nirvahitā）。
- 《Bṛhadāraṇyaka Upaniṣad》I 4.7 / I 2.7：名为不死、色为死灭——名超时间，色归于灭。
- Rhys Davids：其中可见"个体存在根据"的**名的原始信仰**；Walleser：名色是"确立存在者范畴的**最初尝试**"。
- **木村泰贤**：名色＝"身心合成之组织"——和辻反驳：从身心组织无法缘起"有、生、老、死"，且与缘起链脱节；把名色限为"胎儿"更堵塞了与识互缘的论理。

**近代解读**：
- **和辻哲郎**：名＝概念的把握、色＝被把握的特殊限定；识↔名色互缘显示"无始、无根据"；DN 15 的结论（语言道／施設道范围）是对"概念的默示录"——真理只在缘起法的范围内成立。
- **印顺**：五支义即具十支（"结所系法"＝十二处、"味着"＝受、"心"＝识）；名色与识"共俱"，不承认非此世之轮回主体。
- **Dessein**：十支式（以识为首、缺无明行）是大乘"现在世解脱"与阿赖耶识成立的经论跳板——名色↔识互缘正是该式的理论核心。
- **Bodhi**：识↔名色互缘是全缘起链"最深的漩涡"。
